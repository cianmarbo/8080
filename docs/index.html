8080 is an emulator for the Intel 8080, the famous 8-bit microprocessor released by Intel in 1974. It's designed to run the original Space Invaders arcade game designed by Tomohiro Nishikado released in 1978.

Why?

I started this project primarily because I wanted to learn how CPU's worked. While it started out as a small side project; implementing a few Intel 8080 instructions to understand how they worked, eventually I couldn't help myself and became determined to create a fully fledged Space Invaders emulator! :D

Ultimately, my hope is this project inspires and helps others learn about computer architecture!

How it works

Space Invaders ran on an 8080 clocked at 2 MHz, so most of the work is the CPU itself: written in C99, it fetches, decodes and executes the game's instructions one at a time, against a flat 64 KB of memory.

The rest is the cabinet around the CPU. Twice per frame the video hardware interrupts the game, once mid-screen and once at VBlank, and the game uses those moments to draw. Input arrives through I/O ports, and a dedicated shift register moves sprites to any horizontal pixel offset.

The picture lives in 7 KB of video memory at one bit per pixel, laid out for a CRT mounted on its side. Each frame it is rotated upright and drawn through OpenGL.

The CRT

Two shader passes recreate the cabinet's tube. The first blends each frame with a fading copy of the last, so moving pixels leave a short phosphor trail. The second bends the picture into a curved screen with rounded corners, then adds glow, a faint RGB stripe mask and a vignette.

Build and run

The emulator is macOS only for now, and needs a C compiler and SDL2. The game's ROMs aren't included, so you'll need to supply your own. 

brew install sdl2
cd emulator
make build
./8080 invaders.h invaders.g invaders.f invaders.e

5 inserts a coin and 1 starts the game. Move with A and D or the arrow keys, and fire with Space. Game controllers work too. There's no sound yet.
